# Australian Tax & Business Calculators

Free calculators and generators for Australian sole traders and small businesses, built by [Instant Receipts](https://instantreceipts.com.au).

## Tools

| Tool | Description |
|------|-------------|
| [GST Calculator](https://instantreceipts.com.au/tools/gst-calculator) | Add 10% GST to a price, or remove GST from a GST-inclusive total using the 1/11th rule |
| [BAS Calculator](https://instantreceipts.com.au/tools/bas-calculator) | Work out G1, 1A (GST on sales) and 1B (GST on purchases) for your BAS |
| [Sole Trader Tax Calculator](https://instantreceipts.com.au/tools/sole-trader-tax-calculator) | Estimate income tax, Medicare levy, HELP repayment and take-home pay |
| [Mileage Calculator](https://instantreceipts.com.au/tools/mileage-calculator) | ATO cents per km deduction — 91¢/km for 2026-27 |
| [Work From Home Calculator](https://instantreceipts.com.au/tools/work-from-home-calculator) | ATO 70 cents per hour working from home deduction |
| [Invoice & Receipt Generator](https://instantreceipts.com.au/tools/invoice-generator) | Free tax invoice template — add ABN, GST per line, download PDF |

## About

These tools are maintained by [Instant Receipts](https://instantreceipts.com.au), a receipt scanning and bookkeeping app for Australian sole traders and small businesses.

All calculators use current ATO rates and are updated each financial year. They are estimate tools — not tax advice. Always verify at [ato.gov.au](https://www.ato.gov.au) before lodging.

## Usage

These are pure HTML/CSS/JS pages — no build step required. They work as static files served from any web server or GitHub Pages.

## Rates in this release (November 2026)

- **GST rate**: 10% (standard since July 2000)
- **Cents per km 2026-27**: 91¢/km (up to 5,000 km per car)
- **Work from home 2025-26**: 70¢/hour (2026-27 rate not yet published)
- **Income tax**: 2025-26 and 2026-27 brackets included
- **HELP repayment**: 2025-26 and 2026-27 bands included
